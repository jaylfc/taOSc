# Contributing to taOSc

## Shared Xcode scheme

The Xcode project is generated by XcodeGen from `apple/project.yml`. The
committed `apple/taOSc.xcodeproj/` directory is generated at build time and
should not be edited by hand.

To regenerate the project locally:

```bash
brew install xcodegen
xcodegen generate --spec apple/project.yml --project apple
```

Then open `apple/taOSc.xcodeproj` in Xcode. The shared scheme comes from
`project.yml`, not from a committed `taOSc.xcscheme`.
