# Build-test gate preconditions

## Shared Xcode scheme

The project is generated by XcodeGen from `apple/project.yml`. Do not commit
`apple/taOSc.xcodeproj/`. To open it in Xcode run

    brew install xcodegen && xcodegen generate --spec apple/project.yml --project apple

from the repo root. The shared scheme (`taOSc`) comes from the `schemes:` block
in `apple/project.yml`, never from a committed pbxproj. CI
(`.github/workflows/swift-build.yml`) runs the same generate step before
`xcodebuild build test`, so if `project.yml` does not generate locally it will
not build in CI either.

## PR gates

A PR must satisfy:

- build-test (`swift-build.yml`)
- secret-scan (`secret-scan.yml`)
- secret-scan-selftest (`secret-scan.yml`, the self-test must FIND the fixtures under `ci/fixtures/secret-scan/`)
- markdownlint (`lint.yml`)

Green status from CodeRabbit, Gitar, and Kilo Code Review on a PR is diff
review only. It is not compile verification.
